# AvionicsWorkShopSamplePCB
This repo contains the design files for the sample PCB used for the avionics Workshop between Arbalest Rocketry and Astra Labs.

This project was developed in KiCAD 10.0; it requires a similar or newer version to be propely opened. 

The dependencies folder includes the libraries used in this PCB; they might need to be manually imported if shortcut addresses become non-funcitonal of if any directory name is changed.

This project is a bare-minimun design that will likely require non-trivial modifications to match the avionics requirements of a given mission; treat this file as a base from which to build up
your own design.
